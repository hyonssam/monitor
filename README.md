# 2026 성취평가 모니터링 · 자가진단 프로그램

충청북도 고등학교 도단위 성취평가 모니터링을 위한 **오프라인 단일 HTML 도구**입니다.
한국교육과정평가원 모니터링 지표(필수 2종 · 특성 4종)를 과목별로 자동 판정하고,
정기시험 문항과 수행평가 자료로 그 수치가 나온 원인까지 찾아 줍니다.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 소개 · 사용 안내 페이지 (GitHub Pages 첫 화면) |
| `monitor.html` | 프로그램 본체 (단일 파일, 약 2.4MB) |

## 화면 구성

**① 모니터링 입력표** — 학교알리미 · 평가계획 · 분할점수 산출 내역 PDF를 올리면 표가 자동으로 채워집니다. 1·2학기 증감 자동 계산, 과목별 성취도 분포 차트, 엑셀 내보내기, 백업 저장.

**② 평가 자가진단** — 평가원 지표 6종을 `적정 / 주의 / 심각` 3단계로 판정합니다. 지표별 판정 내용과 해석, 셀프 체크리스트(예·아니오·해당없음), 소명 의견란, 컨설팅 권고사항을 자동으로 정리합니다.

**③ 원인 심층분석** — NEIS 정오표와 수행평가 일람표를 올리면
- 학기말 A 비율이 **정기시험**과 **수행평가** 중 어디에서 왔는지 분해
- 문항이 겨냥한 성취수준 학생의 2/3가 맞혔는지 판정 (문항 타게팅)
- 수행평가 영역별 기술통계 · 점수 분포 · 상관 · 신뢰도 α · 성취수준별 히트맵

## 준비물

| 자료 | 내려받는 곳 | 필수 |
|---|---|---|
| 교과별 학업성취 사항 | 학교알리미(정보공시) 화면을 PDF로 인쇄 | 선택 |
| 교수·학습 및 평가 운영 계획 | 한글 원본 → `[파일] ▸ [인쇄] ▸ PDF 저장` | 선택 |
| 정기시험 정오표 | NEIS ▸ 성적 ▸ 정기시험조회 ▸ `교과목별학생답정오표` ▸ [XLS data] | ③ 탭 필수 |
| 수행평가 일람표 | NEIS ▸ 수행평가조회/통계 ▸ `강의실별일람표조회(전체영역)` ▸ [XLS data] | ③ 탭 필수 |
| 문항정보표 | NEIS ▸ `문항정보표` 를 PDF로 저장 | 선택 |

> 평가계획 PDF는 **글자가 살아 있는 파일**이어야 인식됩니다. 결재 문서를 스캔한 PDF는 글자 데이터가 없어 읽을 수 없으며, 프로그램이 이를 감지해 안내합니다.

## 오프라인 사용

- 외부에서 불러오는 리소스가 **0개**입니다. 엑셀 파서(SheetJS)와 PDF 파서(pdf.js)가 파일 안에 포함되어 있습니다.
- `monitor.html` 하나만 내려받아 더블클릭하면 브라우저에서 바로 열립니다. 설치·인터넷 모두 불필요합니다.
- 파일 이름을 바꾸거나 복사하면 입력 내용은 각각 따로 저장됩니다. 옮길 때는 프로그램 안의 `[💾 백업 저장]` → `[📂 백업 열기]`를 사용하세요.

## 개인정보 보호

- 올린 엑셀·PDF는 **브라우저 안에서만** 처리되며 어떤 서버로도 전송되지 않습니다.
- 학생 이름·성적은 외부 저장·공유·기록 어디에도 남지 않으며, 화면에 학생 이름을 표시하지 않습니다.
- 입력한 수치와 체크리스트 응답만 그 컴퓨터의 브라우저(localStorage)에 저장됩니다.

## GitHub Pages 배포

1. 저장소를 만들고 `index.html`, `monitor.html`, `README.md` 를 **저장소 최상위**에 올립니다.
2. `Settings` ▸ `Pages` ▸ Source 를 `Deploy from a branch`, Branch 를 `main` / `(root)` 로 지정합니다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

> 파일명은 한글 대신 영문(`monitor.html`)을 사용했습니다. 한글 파일명은 URL 인코딩 문제로 일부 환경에서 열리지 않을 수 있습니다.

## 판정 결과 해석 시 유의

이 프로그램의 판정은 **학교 자체 점검용 참고 자료**입니다. 평가원·교육청이 실제 컨설팅 대상을 선정할 때는 전국 자료를 이용한 유사 특성 학교군 내 상대 비교를 사용하므로 결과가 다를 수 있습니다. 또한 지표에 걸렸다는 것이 곧 부적절한 평가라는 뜻은 아니며, **설명 가능한 근거를 갖추었는지** 확인하는 데 목적이 있습니다.

기준 과목 평균, A 분할점수 기준 등 공식 통계가 공개되지 않은 항목은 `<선택>`으로 두었고, 비워 두면 해당 지표를 판정하지 않습니다.
