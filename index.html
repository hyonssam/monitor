오프라인으로 쓰는 법

  1. 위의 [💾 내 컴퓨터에 저장] 을 누릅니다. (또는 프로그램 화면에서 Ctrl + S)
  2. 저장된 HTML 파일을 더블클릭 하면 브라우저에서 바로 열립니다. 설치할 것도, 인터넷도 필요 없습니다.
  3. 엑셀·PDF를 읽는 기능까지 파일 안에 들어 있어 랜선을 뽑아도 그대로 동작합니다.
  4. 동료 선생님께는 그 파일 하나만 전달하면 됩니다. (USB·메신저·업무 메일 무관)

⚠ 파일 이름을 바꾸거나 복사하면 입력 내용은 각각 따로 저장됩니다. 옮기실 때는 프로그램 안의 [💾 백업 저장] 으로 .json 파일을 만든 뒤 새 파일에서 [📂 백업 열기] 하세요.

개인정보 보호

✓ 올린 엑셀·PDF는 브라우저 안에서만 처리되며 어떤 서버로도 전송되지 않습니다.

✓ 학생 이름·성적은 외부 저장·공유·기록 어디에도 남지 않습니다. 화면에 학생 이름을 표시하지 않습니다.

✓ 탭을 닫으면 올린 파일은 사라집니다. 입력한 수치와 체크리스트 응답만 그 컴퓨터의 브라우저에 저장됩니다.

✓ 결과 저장은 사용자의 PC로 직접 내려받는 방식입니다. (엑셀 · 백업 .json · 인쇄/PDF)

📋 학습지원 소프트웨어 심의 관련 안내

초·중등교육법 제29조의2에 따른 학습지원 소프트웨어 심의 대상 여부는 다음 두 조건 중 하나 이상을 충족할 때 적용됩니다.

① 학생들의 개인정보를 수집·이용·제공 등 처리하는 소프트웨어
② 교과 성취기준과 관련된 학습콘텐츠를 포함하며, 콘텐츠 제공 기관이 학교 교육과정 운영 지원 목적으로 개발·보급하는 소프트웨어

조건해당근거
① 개인정보 처리비해당파일은 사용자 브라우저 내부에서만 처리. 외부 송신·서버 저장·로그 보관 없음. 결과는 사용자 PC로 직접 저장.
② 학습콘텐츠 + 기관 보급비해당학생용 학습 콘텐츠 없음. 교사가 평가 결과를 점검하기 위한 업무 보조 도구이며 콘텐츠 제공 기관에 의한 보급 구조가 아님.

결론 — 두 조건 모두 비해당하므로 학습지원 소프트웨어 심의 대상이 아닙니다. 다만 학교 내 사용 시 학교장께 사용 사실을 안내·확인하시면 더 안전합니다.

※ 본 안내는 공개된 법령·지침을 토대로 한 일반적 설명이며, 최종 판단은 소속 교육청·학교의 운영 지침에 따라야 합니다.

⚠ 판정 결과 해석 시 유의

이 프로그램의 판정은 학교 자체 점검용 참고 자료입니다. 평가원·교육청이 실제 컨설팅 대상을 선정할 때는 전국 자료를 이용한 유사 특성 학교군 내 상대 비교를 사용하므로 결과가 다를 수 있습니다.

또한 지표에 걸렸다는 것이 곧 부적절한 평가라는 뜻은 아닙니다 — 설명 가능한 근거를 갖추었는지 확인하는 데 목적이 있습니다.
